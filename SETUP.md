# Install this profile README

Your profile repository already exists at:
https://github.com/KartikYadav020307/KartikYadav020307

1. Upload `README.md`, `assets/profile-banner.svg`, and `.github/workflows/snake.yml` into the root of that repository. Keep the folder paths exactly as shown.
2. Commit to the repository's `main` branch. GitHub will render `README.md` automatically on your profile.
3. Open the repository's **Actions** tab and check **Generate contribution snake**. If it did not run automatically, select **Run workflow** once.
4. If the workflow cannot publish the `output` branch, open **Settings → Actions → General → Workflow permissions**, enable read/write access for workflows, save, and run the workflow again.

The stats cards and contribution-streak card are served by third-party services and may occasionally be rate-limited or unavailable. They update independently of this repository.
